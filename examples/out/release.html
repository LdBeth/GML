Contact your representative for the support schedule.

Changes in 4.2

The following changes were made:

  1. 1. Faster start-up
  2. 2. New quiet start option
  3. 3. Fixes for the problems listed in Figure 1

This release has 3 changes (see footnote 1).

Important: Back up the configuration before you upgrade.

Configuration

The configuration file now accepts these keywords:

timeout
Seconds to wait for a client (default 30).
quiet
Suppresses the start-up banner.

An example: 

  server  main
    timeout 45
    quiet

Platforms

Supported platforms:

  • z/VM
  • Linux on Z
