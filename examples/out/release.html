Configuration

The configuration file now accepts these keywords:

timeout
Seconds to wait for a client (default 30).
quiet
Suppresses the start-up banner.

An example: 

  server  main
    timeout 45
    quiet

Capacity planning

Each worker thread of Widget Server 4.2 serves about \(r = 250\) requests per second, so a server with \(w = 8\) workers handles at most \[T = w \cdot r = 8 \cdot 250 = 2000\](1)requests per second, or 172800000 requests a day.

At start-up the 12 cache shards are warmed one after another, and shard \(k\) takes \(k\) seconds, so the warm-up takes \[\sum_{k=1}^{12} k = {12(12+1)\over 2} = 78\ {\rm s}\](2)before the server accepts requests.

Plan the offered load \(\lambda\) so that the utilisation \(\rho\) stays at or below 0.8. With \(\lambda = 1600\) requests per second and \(T\) from (1), \[\rho = {\lambda \over T} = {1600 \over 2000} = 0.80 \le 0.8\](3)If \(\rho\) in (3) rises above the limit, add workers: by (1) each one adds 250 requests per second.
